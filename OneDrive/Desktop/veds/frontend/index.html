How Veds Works

Effortless browser-to-browser screen sharing across operating systems in three simple steps.

01

Create a Room

Open Veds on Device A and click "Create Room" to generate a secure, temporary 6-digit passkey.

02

Join with Passkey

Open Veds on Device B, enter the passkey, and click "Join Room". Both devices connect in real-time.

03

Two-Way Screen Share

Click "Share My Screen" on either device. Audio and video are securely transmitted peer-to-peer via WebRTC.

Security & Architecture

Transparent, lightweight, and engineered for privacy.

Peer-to-Peer Encryption

Veds uses WebRTC for peer-to-peer media communication and a signaling server to help establish the connection. Once established, media flows directly between devices encrypted via standard DTLS/SRTP.

No Persistent Data Storage

No database is used. Passkeys and rooms are kept in temporary backend server memory only while active and are immediately deleted when users leave.

No Cables or Extra Hardware

Works without HDMI cords, USB cables, capture cards, or Raspberry Pi. Only modern browsers and an internet/network connection are needed.

About Veds

Veds is built to make cross-device screen sharing frictionless. Whether you are presenting from a laptop to a conference display, reviewing a project with a colleague on another computer, or casting to a tablet, Veds establishes an instant two-way connection in seconds without signups, software installations, or proprietary dongles.
